# 18장 학습을 돌리는 일

<sub>4부 신경망 · 표제어 36개 · 도해 3개</sub>

> **여는 지도** — 이 장의 낱말 서른여섯. 한 스텝이 도는 다섯 자리

이 장은 17장의 부품으로 만든 망을 실제로 학습시키는 절차를 다룬다. 한 스텝이 도는 다섯 걸음이 있고, 각 걸음마다 이름 붙은 문제와 대책이 있다.

절차 자체는 단순하다. 데이터를 조금 가져와서, 통과시키고, 얼마나 틀렸는지 재고, 기울기를 구하고, 가중치를 조금 옮긴다. 이것을 수십만 번 반복한다. 어려운 것은 그 반복이 안정되게 도는가다.

실패하는 모양이 정해져 있다. 손실이 안 내려가거나, 갑자기 치솟거나, 계산이 깨져서 값이 사라진다. 이 셋을 각각 다루는 낱말들이 이 장에 있다. 25장의 사전학습이 이 절차를 아주 크게 돌리는 일이고, 26장의 정렬도 손실만 바꾼 같은 절차다.

## 한눈에 보기

| 무리 | 무엇을 다루나 | 어디서 다시 쓰나 |
|---|---|---|
| 배치와 데이터 | 한 번에 얼마씩 넣나 | 25장, 41장 |
| 기울기 문제 | 사라지고 폭발하는 것 | 20장, 23장 |
| 최적화 방법 | 어느 방향으로 얼마나 | 26장 정렬 |
| 학습률 일정 | 보폭을 언제 줄이나 | 25장 학습 곡선 |
| 메모리와 정밀도 | 큰 모델을 어떻게 올리나 | 28장, 50장 |


## 표제어

### 데이터를 넣는 방식

#### 경사하강

<sub>Gradient Descent</sub>

**손실의 기울기를 구하고 그 반대 방향으로 가중치를 조금 옮기는 절차.**

<sub>관련어 SGD, 미니배치, 학습률, 손실 지형(11장)</sub>

- **SGD** `Stochastic Gradient Descent` — 데이터를 무작위로 조금씩 뽑아 기울기를 구하는 경사하강. 확률적이라는 말이 그 무작위를 가리킨다.
- **미니배치** `Mini-batch` — 한 번의 갱신에 쓰는 데이터 묶음. 전체도 아니고 하나도 아닌 중간 크기. <sub>관련어 배치 크기, 셔플, 기울기 누적, 배치(13장)</sub>
- **배치 크기** `Batch Size` — 미니배치에 담는 데이터 개수. 메모리 한계가 실제로 이 값을 정하는 경우가 많다.
- **셔플** `Shuffle` — 에폭마다 데이터 순서를 섞는 일. 안 섞으면 같은 순서로 배우면서 순서 자체를 외운다.
- **데이터 로더** `Data Loader` — 데이터를 읽어 배치로 묶어 넘겨 주는 부분. 여기가 느리면 가속기가 놀아서, 학습 속도의 병목이 되기도 한다.
- **기울기 누적** `Gradient Accumulation` — 작은 배치를 여러 번 통과시켜 기울기를 더한 뒤 한 번 갱신하는 방식. 메모리가 모자랄 때 큰 배치와 같은 효과를 낸다.

### 기울기가 사라지고 폭발하는 문제

#### 기울기 소실

<sub>Vanishing Gradient</sub>

**역전파에서 앞쪽 층으로 갈수록 기울기가 0에 가까워져 학습이 안 되는 현상.**

<sub>관련어 기울기 폭발, 잔차 연결(17장), ReLU(17장), 연쇄 법칙(11장)</sub>

- **기울기 폭발** `Exploding Gradient` — 기울기가 층을 지나며 계속 커져서 가중치가 터무니없이 크게 옮겨지는 현상. <sub>관련어 기울기 클리핑, 기울기 소실, 발산(13장)</sub>
- **기울기 클리핑** `Gradient Clipping` — 기울기의 크기를 정한 값 이하로 잘라 내는 장치. 학습이 가끔 터지는 것을 막는 안전장치다.
- **손실 급등** `Loss Spike` — 학습 도중 손실이 갑자기 크게 오르는 현상. 큰 모델의 사전학습에서 관찰되고, 이전 체크포인트로 되돌려 다시 돌리기도 한다.
- **수치 불안정** `Numerical Instability` — 계산이 넘치거나 0이 되어 값이 깨지는 상태. 1장의 부동소수점 범위 문제가 여기서 실제 사고가 된다.

### 어느 방향으로 얼마나 옮길 것인가

**최적화 방법 다섯과 각각이 더한 것**

| 방법 | 무엇을 더했나 | 쓰이는 자리 |

|---|---|---|

| SGD | 기본. 기울기 방향으로 간다 | 이미지 쪽 일부 |

| 모멘텀 | 이전 방향을 관성으로 이어 간다 | 흔들림을 줄인다 |

| RMSProp | 파라미터마다 보폭을 다르게 | 기울기 크기가 제각각일 때 |

| 아담 | 관성과 개별 보폭을 둘 다 | 사실상 기본값 |

| AdamW | 아담에서 가중치 감쇠를 분리 | 큰 모델의 표준 |

아래로 갈수록 파라미터마다 들고 있어야 할 상태가 는다.
아담은 가중치 하나당 두 개의 값을 더 들고 있어서, 메모리가 파라미터의 세 배쯤 든다.
50장에서 학습 메모리를 계산할 때 이 사실이 그대로 나온다.

- **모멘텀** `Momentum` — 이전에 가던 방향을 일정 비율로 이어 가는 장치. <sub>관련어 SGD, 아담, 손실 지형(11장)</sub>

#### 아담

<sub>Adam</sub>

**관성과 파라미터별 보폭 조절을 함께 쓰는 최적화 방법.**

<sub>관련어 모멘텀, AdamW, 가중치 감쇠(16장), 옵티마이저 상태</sub>

- **AdamW** `AdamW` — 가중치 감쇠를 손실이 아니라 갱신 단계에서 적용하는 아담 변형. 큰 언어 모델 학습의 표준 선택이다.
- **옵티마이저 상태** `Optimizer State` — 최적화 방법이 파라미터마다 들고 있는 보조 값들. 학습 메모리의 큰 부분을 차지한다.
- **RMSProp** `Root Mean Square Propagation` — 기울기 제곱의 이동 평균, 곧 제곱 평균 제곱근으로 파라미터마다 보폭을 조절하는 방법. 아담의 절반에 해당한다.
- **이차 방법** `Second-Order Method` — 곡률까지 보고 방향을 정하는 최적화. 이론적으로 빠르고 계산과 메모리가 커서 큰 모델에서는 잘 안 쓴다.

### 보폭을 언제 줄일 것인가

#### 학습률 스케줄

<sub>Learning Rate Schedule</sub>

**학습이 진행되는 동안 학습률을 계획대로 바꾸는 방식.**

<sub>관련어 워밍업, 코사인 감쇠, 학습률(13장), 손실 곡선(25장에서 다룬다)</sub>

- **워밍업** `Warmup` — 학습 초반에 학습률을 0에서 목표치까지 서서히 올리는 구간. 초반 불안정을 막는다.
- **코사인 감쇠** `Cosine Decay` — 학습률을 코사인 곡선을 따라 부드럽게 줄이는 일정. 널리 쓰이는 기본 선택이다.
- **계단식 감쇠** `Step Decay` — 정해진 시점마다 학습률을 몇 분의 일로 떨어뜨리는 방식.
- **재시작** `Warm Restart` — 학습률을 줄이다가 다시 올리기를 반복하는 일정. 얕은 골을 빠져나오게 하려는 시도다.

### 큰 모델을 메모리에 올리기

- **혼합 정밀도** `Mixed Precision` — 계산은 낮은 정밀도로 하고 중요한 부분만 높은 정밀도로 유지하는 학습 방식. <sub>관련어 정밀도(1장), bf16(1장), 수치 불안정, 양자화(28장에서 다룬다)</sub>
- **손실 스케일링** `Loss Scaling` — 작은 기울기가 0으로 사라지지 않게 손실을 일부러 크게 곱하는 요령. 낮은 정밀도 학습에서 쓴다.
- **활성화 체크포인팅** `Activation Checkpointing` — 역전파에 필요한 중간 값을 전부 저장하지 않고 일부만 남긴 뒤 필요할 때 다시 계산하는 기법. <sub>갈리는 자리: 학습 상태를 저장하는 체크포인트와 이름이 같아 문서에서 섞인다 · 관련어 순전파(17장), 기울기 누적, 메모리 계층(2장)</sub>
- **오프로딩** `Offloading` — 가속기 메모리에 안 들어가는 것을 주기억 장치나 저장 장치로 내려 두는 방식. 돌아가게는 하고 크게 느려진다.
- **ZeRO** `Zero Redundancy Optimizer` — 옵티마이저 상태와 기울기와 가중치를 여러 장치에 나눠 들고 있어 중복을 없애는 방식. 50장의 분산 학습에서 다시 나온다.
- **메모리 사용량 계산** `Memory Estimation` — 가중치와 기울기와 옵티마이저 상태와 활성값을 각각 세어 필요한 메모리를 미리 잡는 일. 학습을 시작하기 전에 반드시 하는 계산이다.

### 학습을 지켜보기

- **학습 모니터링** `Training Monitoring` — 학습이 도는 동안 손실과 기울기 크기와 학습률 같은 값을 기록하고 보는 일. <sub>관련어 손실 곡선, 검증 손실(16장), 발산(13장)</sub>
- **손실 곡선** `Loss Curve` — 스텝에 따라 손실이 어떻게 변하는지 그린 그래프. 25장에서 이 곡선의 모양을 읽는 이야기가 나온다.
- **실험 추적** `Experiment Tracking` — 어떤 설정으로 어떤 결과가 나왔는지 기록해 두는 일. 안 하면 무엇 때문에 좋아졌는지 못 찾는다.
- **어블레이션** `Ablation` — 떼어 낸다는 뜻이고, 구성 요소를 하나씩 빼 보며 각각이 얼마나 기여했는지 확인하는 실험이다. 무엇이 실제로 효과가 있었는지 가리는 유일한 방법이다.
- **시드 고정** `Seed Fixing` — 무작위성을 같은 값으로 고정해 결과를 재현하는 일. 완전한 재현은 가속기 연산 순서 때문에 어려운 경우가 있다.
- **학습 재개** `Resume` — 끊긴 학습을 체크포인트에서 이어서 하는 일. 옵티마이저 상태와 데이터 위치까지 되살려야 정확히 이어진다.
- **과학습** `Overtraining` 〔유동〕 — 필요한 것보다 오래 학습시키는 일. 과적합을 뜻하기도 하고, 25장에서는 작은 모델에 데이터를 아주 많이 먹이는 전략을 가리키기도 한다.

## 자주 헷갈리는 짝

- **기울기 소실과 기울기 폭발** 같은 점은 둘 다 곱셈이 반복되어 생긴다는 것.
다른 점은 방향이다. 대책도 다르다. 앞은 구조로, 뒤는 클리핑으로 푼다.
- **학습률과 배치 크기** 같은 점은 둘 다 한 스텝의 크기에 관여한다는 것.
다른 점은 무엇을 정하는가다. 둘을 같이 바꿔야 하는 관계다.
- **체크포인트 (저장)와 체크포인팅 (활성값)** 같은 낱말이고 뜻이 다르다.
앞은 학습 상태를 파일로 남기는 일이고 뒤는 중간 값을 다시 계산하는 기법이다.
- **모멘텀과 학습률** 같은 점은 둘 다 얼마나 옮길지에 관여한다는 것.
다른 점은 앞이 방향의 관성이고 뒤가 크기라는 것.
- **에폭과 스텝** 데이터 전체를 한 바퀴 도는 것과 한 번 갱신하는 것.
큰 모델의 사전학습에서는 에폭보다 스텝과 토큰 수로 진행을 센다.

## 지금 움직이는 것

학습 절차의 낱말은 안정되었는데 규모가 낱말의 무게를 바꿨다. 예전에는 최적화 방법을 고르는 것이 큰 결정이었고, 지금은 아담 계열이 사실상 유일한 선택이라 논의가 줄었다. 대신 메모리를 어떻게 나누고 장치 사이 통신을 어떻게 줄이는가가 중심이 되었다. 50장이 그 이야기를 다룬다.

## 더 볼 곳

여기서 나온 절차가 25장의 사전학습에서 아주 큰 규모로 돌아간다. 혼합 정밀도는 28장의 양자화로 이어지고, 메모리와 분산은 50장에서 다시 나온다.
