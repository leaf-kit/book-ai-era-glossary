# 17장 신경망의 부품

<sub>4부 신경망 · 표제어 39개 · 도해 4개</sub>

> **여는 지도** — 이 장의 낱말 서른아홉. 아래에서 위로 조립하면 신경망 하나가 된다

이 장은 신경망을 부품 단위로 뜯는다. 14장의 선형회귀 하나가 여기서 뉴런 하나가 되고, 그것을 겹쳐 쌓으면 신경망이 된다.

핵심은 두 가지다. 가중합과 비선형 함수. 가중합만 쌓으면 아무리 깊어도 결국 하나의 가중합과 같아진다. 사이사이에 비선형 함수를 끼워야 층이 늘어난 만큼 표현력이 는다. 이 사실 하나가 신경망의 모양을 정했다.

23장의 트랜스포머가 여기 나오는 부품으로 만들어진다. 완전연결 층과 층 정규화와 잔차 연결은 그대로 쓰이고, 어텐션이라는 새 부품 하나가 더해진다. 이 장을 읽고 나면 23장의 그림에서 새로운 것이 하나뿐이라는 것이 보인다.

## 한눈에 보기

| 무리 | 무엇을 다루나 | 어디서 다시 쓰나 |
|---|---|---|
| 계산 단위 | 가중합 하나 | 23장 피드포워드 |
| 비선형 | 층을 쌓는 것을 뜻있게 만드는 것 | 23장, 27장 |
| 층과 표현 | 쌓아 올린 구조와 그 안의 값 | 22장 임베딩 |
| 연결 방식 | 깊어져도 학습되게 만드는 장치 | 23장 블록 |
| 학습 장치 | 앞으로 가고 뒤로 고친다 | 18장 |


## 표제어

### 계산 단위 하나

#### 뉴런

<sub>Neuron</sub>

**여러 입력에 각각 가중치를 곱해 더하고, 그 값에 함수를 씌워 하나의 수를 내는 계산 단위.**

<sub>관련어 가중치, 편향 (신경망), 활성화 함수, 층, 선형회귀(14장)</sub>

- **가중치** `Weight` — 입력에 곱해지는 수. 학습으로 정해지고, 모델 크기를 셀 때 세는 대상이 이것이다.
- **편향 (신경망)** `Bias` — 가중합에 더해 주는 수. 함수 전체를 위아래로 옮기는 역할이다. 10장의 표집 편향, 16장의 모델 편향과 완전히 다른 낱말이다.
- **가중합** `Weighted Sum` — 입력마다 가중치를 곱해 전부 더한 값. 11장의 내적과 같은 계산이다.
- **퍼셉트론** `Perceptron` — 신경망의 초기 형태. 하나로는 직선으로 못 가르는 문제를 못 푼다는 한계가 알려지면서 연구가 한동안 멈췄다.

### 비선형 함수

#### 활성화 함수

<sub>Activation Function</sub>

**가중합에 씌우는 비선형 함수. 층을 쌓는 것을 뜻있게 만든다.**

<sub>관련어 ReLU, 시그모이드, 소프트맥스, 기울기 소실(18장에서 다룬다)</sub>

- **ReLU** `Rectified Linear Unit` — 0보다 작으면 0, 크면 그대로 내보내는 활성화 함수. <sub>관련어 활성화 함수, GELU, 죽은 뉴런</sub>
- **죽은 뉴런** `Dying ReLU` — 항상 0을 내보내게 되어 학습이 멈춘 뉴런. 학습률이 크면 자주 생긴다.
- **GELU** `Gaussian Error Linear Unit` — 0 근처를 부드럽게 만든 활성화 함수. 트랜스포머 계열에서 널리 쓰인다.
- **SwiGLU** `SwiGLU` — 입력을 두 갈래로 나눠 한쪽이 다른 쪽을 얼마나 통과시킬지 조절하게 만든 활성화 방식. 이름은 Swish라는 활성화 함수와 게이트 구조 (GLU)를 합친 데서 왔다. 최근 언어 모델의 피드포워드에서 자주 쓰인다.
- **탄젠트 함수** `Tanh` — 쌍곡탄젠트를 줄여 부르는 이름이고, 출력을 -1과 1 사이로 눌러 담는 S자 함수다. 시그모이드와 성질이 비슷하고 중심이 0이다.
- **소프트맥스** `Softmax` — 여러 수를 전부 양수로 만들고 합이 1이 되게 나누어 확률처럼 만드는 함수. <sub>관련어 확률(10장), 온도(27장에서 다룬다), 어텐션(23장에서 다룬다), 로짓(27장에서 다룬다)</sub>

### 층과 그 안의 값

#### 층

<sub>Layer</sub>

**같은 입력을 받아 나란히 계산하는 뉴런들의 묶음. 그리고 그런 묶음 하나가 지나는 단계.**

<sub>관련어 은닉층, 완전연결, 표현, 깊이와 폭, 딥러닝</sub>

- **딥러닝** `Deep Learning` — 층을 여러 개 쌓은 신경망으로 하는 기계학습. 몇 층부터 깊은지에 대한 기준은 없다.
- **은닉층** `Hidden Layer` — 입력층과 출력층 사이의 층. 값을 사람이 직접 보지 않는다는 뜻에서 붙은 이름이다.
- **완전연결 층** `Fully Connected Layer` — 앞 층의 모든 값이 다음 층의 모든 뉴런에 연결된 층. 조밀 층이라고도 부른다. 23장의 피드포워드가 이것이다.
- **표현** `Representation` — 모델이 내부에서 만들어 낸 벡터. 입력을 그 층까지 처리한 결과다. <sub>관련어 임베딩(22장에서 다룬다), 특징(12장), 표현 학습, 잠재 공간(21장에서 다룬다)</sub>
- **표현 학습** `Representation Learning` — 유용한 표현을 데이터에서 스스로 찾게 하는 것. 사람이 특징을 설계하던 자리를 대신한다.
- **깊이와 폭** `Depth and Width` — 층의 개수와 층 하나의 뉴런 개수. 같은 파라미터를 어느 쪽에 쓸지가 설계의 선택이다.
- **병목 층** `Bottleneck Layer` — 일부러 좁게 만든 층. 정보를 압축하게 만들어 중요한 것만 남기게 한다. 21장의 오토인코더가 이 구조다.

### 깊어져도 학습되게 하는 장치

#### 잔차 연결

<sub>Residual Connection</sub>

**층의 출력에 그 층의 입력을 그대로 더해 주는 연결.**

<sub>관련어 스킵 연결, 층 정규화, 기울기 소실(18장에서 다룬다), 역전파</sub>

- **스킵 연결** `Skip Connection` — 층을 건너뛰어 값을 전달하는 연결. 잔차 연결과 거의 같은 뜻으로 쓰인다.
- **정규화 층** `Normalization Layer` — 층을 지난 값들의 분포를 일정한 범위로 맞춰 주는 층. <sub>관련어 배치 정규화, 층 정규화, RMS 정규화, 잔차 연결</sub>
- **배치 정규화** `Batch Normalization` — 배치 안의 값들로 평균과 분산을 맞추는 층. 이미지 쪽에서 널리 쓰이고, 배치가 작으면 불안정해진다.
- **층 정규화** `Layer Normalization` — 한 데이터의 벡터 안에서 평균과 분산을 맞추는 층. 배치 크기와 무관해서 트랜스포머의 표준이 되었다.
- **RMS 정규화** `RMS Normalization, RMSNorm` — 평균 빼기를 생략하고 크기만 맞추는 방식. 계산이 조금 싸고 성능이 비슷해 최근 모델에서 많이 쓴다.
- **사전 정규화** `Pre-Norm` — 정규화를 층에 들어가기 전에 두는 배치. 깊은 망에서 학습이 안정되어 지금은 대부분 이 방식이다.

### 앞으로 가고 뒤로 고치기

- **순전파** `Forward Pass` — 입력을 층마다 차례로 통과시켜 출력을 만드는 과정. <sub>관련어 역전파, 추론(27장에서 다룬다), 활성화 체크포인팅(18장에서 다룬다)</sub>

#### 역전파

<sub>Backpropagation</sub>

**출력에서 시작해 뒤에서 앞으로 기울기를 계산하며 각 가중치를 어떻게 고칠지 정하는 절차.**

<sub>관련어 순전파, 연쇄 법칙(11장), 그래디언트(11장), 기울기 소실(18장에서 다룬다)</sub>

- **초기화** `Initialization` — 학습을 시작하기 전에 가중치에 어떤 값을 넣어 둘지 정하는 일. <sub>관련어 가중치, 기울기 소실(18장에서 다룬다), 대칭 깨기</sub>
- **대칭 깨기** `Symmetry Breaking` — 같은 층의 뉴런들이 서로 다른 것을 배우게 만드는 일. 무작위 초기화가 그 역할을 한다.
- **활성값** `Activation` 〔유동〕 — 층을 지나 나온 값. 활성화 함수를 뜻하기도 해서 문맥으로 갈라 읽어야 한다.
- **기울기 흐름** `Gradient Flow` — 역전파에서 기울기가 앞쪽 층까지 잘 전달되는 정도. 구조 설계의 중요한 판단 기준이다.

**신경망 계열 네 가지와 각각의 가정**

| 계열 | 어떤 가정을 심었나 | 어디에 맞나 |

|---|---|---|

| 완전연결 | 가정 없음. 다 이어져 있다 | 표 데이터, 작은 입력 |

| 합성곱 | 근처끼리 관련 있다 | 이미지, 격자 데이터 |

| 순환 | 순서가 있고 앞이 뒤에 영향을 준다 | 시계열, 옛 언어 모델 |

| 어텐션 | 어느 자리든 직접 볼 수 있다 | 언어, 긴 의존 |

가정을 강하게 심으면 적은 데이터로 배우고 유연성이 준다.
어텐션은 가정이 가장 약한 편이라 데이터가 많이 필요하고,
데이터가 충분해지자 다른 계열을 넘어섰다.
13장의 귀납 편향이 이 표의 둘째 칸이다.

- **피드포워드 신경망** `Feedforward Neural Network` — 앞으로만 흐르고 되돌아가는 연결이 없는 신경망. 완전연결 층을 쌓은 가장 기본 형태다.
- **MLP** `Multi-Layer Perceptron` — 완전연결 층을 여러 개 쌓은 신경망. 23장의 트랜스포머 블록 안에도 이것이 들어 있다.
- **보편 근사 정리** `Universal Approximation Theorem` 〔유동〕 — 은닉층 하나로도 어떤 연속 함수든 원하는 만큼 가깝게 흉내 낼 수 있다는 정리. 가능하다는 말이지 배울 수 있다는 말은 아니라 자주 오독된다.
- **파라미터 수** `Parameter Count` — 모델 안의 가중치와 편향의 총 개수. 완전연결 층 하나의 파라미터는 입력 수와 출력 수를 곱한 값이다.
- **FLOPs (모델)** `FLOPs` — 한 번의 순전파에 드는 연산 횟수. 2장의 초당 연산 능력과 단위가 비슷해 헷갈리는데, 이쪽은 총량이다.
- **희소 활성화** `Sparse Activation` — 일부 뉴런만 켜지는 성질. 계산을 아낄 수 있고, 25장의 전문가 혼합이 이 발상을 구조로 만든 것이다.

## 자주 헷갈리는 짝

- **편향 (신경망)과 편향 (모델)** 같은 글자이고 뜻이 다르다.
앞은 더해 주는 값이고 뒤는 16장의 오차 원인이다.
- **활성화 함수와 활성값** 같은 낱말에서 나왔고 가리키는 것이 다르다.
앞은 함수이고 뒤는 그 함수를 지난 값이다.
- **배치 정규화와 층 정규화** 같은 점은 둘 다 값의 분포를 맞춘다는 것.
다른 점은 무엇을 기준으로 하는가다. 앞은 배치, 뒤는 한 데이터의 벡터다.
- **순전파와 추론** 같은 점은 둘 다 입력에서 출력을 만든다는 것.
다른 점은 맥락이다. 학습 중의 한 단계인가 실제로 쓰는 것인가.
- **역전파와 최적화** 같은 점은 둘 다 학습의 일부라는 것.
다른 점은 역할이다. 역전파는 기울기를 구하고 최적화는 그것으로 어떻게 옮길지 정한다.

## 지금 움직이는 것

부품 목록이 좁아졌다. 활성화 함수와 정규화 방식이 여러 갈래로 실험되다가 최근 몇 해 사이 몇 가지로 수렴했다. 이유는 성능 차이가 크지 않고 가속기에서 잘 도는 쪽이 선택되었기 때문이다. 2장에서 말한 하드웨어가 구조를 정하는 흐름이 여기서도 보인다.

## 더 볼 곳

여기서 만든 부품으로 18장에서 실제 학습 절차를 돌린다. 19장부터 21장까지가 이 부품을 다르게 조립한 세 가지 계열이고, 23장에서 어텐션이 더해져 트랜스포머가 된다.
