# 14장 고전 기계학습 모델

<sub>3부 기계학습의 뼈대 · 표제어 39개 · 도해 3개</sub>

> **여는 지도** — 이 장의 낱말 서른아홉. 신경망 이전에 만들어졌고 지금도 쓰이는 것들

이 장은 신경망 이전에 만들어진 방법들을 다룬다. 낡은 것을 소개하려는 것이 아니다. 지금도 쓰이고, 어떤 자리에서는 신경망보다 낫다.

표 형태의 데이터에서 특히 그렇다. 행이 수만 개이고 열이 수십 개인 데이터에서는 부스팅 계열이 여전히 강하다. 학습이 몇 초에 끝나고, 왜 그렇게 판단했는지 볼 수 있고, 데이터가 적어도 돈다. 신경망은 이 세 가지를 다 못 한다.

그리고 이 장의 낱말이 뒤에서 계속 나온다. 시그모이드는 17장의 활성화 함수이고, 커널 기법의 아이디어는 어텐션과 닮았으며, 주성분 분석은 22장의 임베딩을 볼 때 쓰인다. 14장을 건너뛰면 4부에서 이 낱말들이 하늘에서 떨어진 것처럼 보인다.

## 한눈에 보기

| 무리 | 어떻게 판단하나 | 어디서 다시 쓰나 |
|---|---|---|
| 선을 긋는 것 | 가중합으로 경계를 만든다 | 17장 뉴런 |
| 나무를 심는 것 | 조건으로 계속 쪼갠다 | 표 데이터 실무 |
| 가까운 것을 보는 것 | 비슷한 사례를 찾는다 | 34장 벡터 검색 |
| 왜 그렇게 답했나 | 판단의 근거를 사람이 읽는다 | 30장, 49장 |
| 묶고 줄이는 것 | 정답 없이 구조를 찾는다 | 22장 임베딩 분석 |


## 표제어

### 선을 긋는 방법

#### 선형회귀

<sub>Linear Regression</sub>

**입력에 각각 무게를 곱해 더한 값으로 수를 예측하는 가장 단순한 모델.**

<sub>관련어 계수, 로지스틱 회귀, 최소제곱법, 뉴런(17장에서 다룬다)</sub>

- **계수** `Coefficient` — 각 입력에 곱해지는 무게. 크기와 부호로 그 항목의 영향을 읽는다.
- **절편** `Intercept` — 입력이 전부 0일 때의 예측값. 17장의 편향과 같은 역할이다.
- **최소제곱법** `Least Squares` — 오차의 제곱합을 가장 작게 만드는 계수를 찾는 방법. 선형회귀에서는 공식으로 한 번에 구할 수 있다.
- **로지스틱 회귀** `Logistic Regression` — 가중합에 시그모이드를 씌워 0과 1 사이의 확률을 내는 분류 모델. <sub>갈리는 자리: 이름에 회귀가 있지만 분류 모델이다 · 관련어 시그모이드, 선형회귀, 분류(13장), 로짓(27장에서 다룬다)</sub>
- **시그모이드** `Sigmoid` — 어떤 수든 0과 1 사이로 눌러 담는 S자 함수. 17장에서 활성화 함수로 다시 나오고, 큰 값에서 기울기가 거의 0이 되는 문제가 있다.
- **서포트 벡터 머신** `Support Vector Machine, SVM` — 두 부류 사이의 간격이 가장 넓어지는 경계를 찾는 모델. 경계 근처의 몇 개 점만 결과를 정한다. 딥러닝 이전에 널리 쓰였다.
- **커널 기법** `Kernel Trick` — 데이터를 더 높은 차원으로 옮긴 것처럼 계산하되 실제로는 안 옮기는 방법. <sub>관련어 서포트 벡터 머신, 내적(11장), 커널 (운영체제)(3장), 커널 (합성곱)(19장에서 다룬다)</sub>
- **다항 특징** `Polynomial Features` — 입력을 제곱하거나 곱해서 새 항목을 만드는 일. 선형 모델로 곡선을 잡게 해 준다.

### 조건으로 쪼개는 방법

#### 결정트리

<sub>Decision Tree</sub>

**조건을 하나씩 물어보며 데이터를 쪼개 내려가는 모델.**

<sub>관련어 불순도, 가지치기 (트리), 랜덤 포레스트, 부스팅</sub>

- **불순도** `Impurity` — 한 묶음 안에 여러 부류가 얼마나 섞여 있는지 재는 값. 지니 불순도와 엔트로피가 흔히 쓰이고, 이 값이 가장 많이 줄어드는 질문을 고른다.
- **가지치기 (트리)** `Pruning` — 너무 깊게 자란 나무의 가지를 잘라 단순하게 만드는 일. 과적합을 막는다. 28장의 신경망 가지치기와 같은 이름이고 목적이 다르다.
- **깊이** `Depth` — 뿌리에서 잎까지의 최대 단계 수. 깊으면 세밀하고 외우기 쉽다.
- **앙상블** `Ensemble` — 여러 모델의 예측을 합쳐 하나의 답을 만드는 방식. <sub>관련어 랜덤 포레스트, 부스팅, 배깅, 앙상블(16장에서 다룬다)</sub>
- **배깅** `Bagging` — 같은 데이터에서 중복을 허용해 다시 뽑기를 여러 번 하고, 뽑을 때마다 모델을 따로 만들어 평균 내는 방식. 결과의 흔들림을 줄인다.
- **랜덤 포레스트** `Random Forest` — 데이터와 항목을 무작위로 뽑아 나무를 여러 개 만들고 투표시키는 모델. <sub>관련어 배깅, 결정트리, 부스팅, 특징 중요도</sub>

#### 그래디언트 부스팅

<sub>Gradient Boosting</sub>

**앞선 모델이 틀린 부분을 다음 모델이 맞히도록 나무를 차례로 이어 붙이는 방식.**

<sub>관련어 랜덤 포레스트, 결정트리, 앙상블, 조기 종료(16장에서 다룬다)</sub>

- **특징 중요도** `Feature Importance` 〔유동〕 — 어떤 항목이 예측에 얼마나 기여했는지 재는 값. 계산 방식에 따라 순위가 달라져서 해석에 주의가 필요하다.

### 가까운 것을 보는 방법

- **k최근접 이웃** `k-Nearest Neighbors, kNN` — 새 데이터와 가장 가까운 k개의 학습 데이터를 찾아 그들의 답을 따르는 방법. <sub>관련어 거리 척도, 근사 최근접 이웃(34장에서 다룬다), 코사인 유사도(11장)</sub>
- **거리 척도** `Distance Metric` — 두 데이터가 얼마나 먼지 재는 방식. 무엇을 거리로 삼느냐가 결과를 정한다.
- **나이브 베이즈** `Naive Bayes` — 모든 항목이 서로 독립이라고 가정하고 베이즈 정리로 계산하는 분류기. 가정이 대개 틀린데도 잘 도는 경우가 많다. 초기 스팸 필터가 이 방식이었다.

### 왜 그렇게 답했는지 보기

- **해석 가능성** `Interpretability` 〔유동〕 — 모델이 왜 그 답을 냈는지 사람이 알아볼 수 있는 정도. <sub>갈리는 자리: 모델이 투명한 것과 설명을 붙일 수 있는 것을 같은 낱말로 부른다 · 관련어 SHAP과 LIME, 특징 중요도, 해석 가능한 모델, 기계적 해석 가능성(30장에서 다룬다)</sub>
- **순열 중요도** `Permutation Importance` — 한 특징의 값을 뒤섞었을 때 성능이 얼마나 떨어지는지로 중요도를 재는 방법. 서로 상관 높은 특징이 있으면 값이 흩어진다.
- **부분 의존도** `Partial Dependence` — 한 특징을 바꿔 갈 때 예측이 평균적으로 어떻게 변하는지 그린 것. 관계의 모양을 보여 준다.
- **반사실 설명** `Counterfactual Explanation` — 무엇이 얼마나 달랐으면 답이 뒤집혔을지를 보여 주는 설명. 대출 거절 같은 자리에서 사람이 실제로 원하는 형태다.
- **대리 모델** `Surrogate Model` — 복잡한 모델의 답을 흉내 내도록 학습시킨 단순한 모델. 그 단순한 쪽을 읽어 원래 모델을 짐작한다. 흉내가 얼마나 맞는지를 같이 봐야 한다.
- **특징 시각화** `Feature Visualization` — 어떤 입력이 특정 단위를 가장 세게 켜는지 그려 보는 방법. 19장의 합성곱 신경망에서 먼저 쓰였다.

### 정답 없이 구조 찾기

#### 군집화

<sub>Clustering</sub>

**정답 없이 비슷한 것끼리 묶는 일.**

<sub>관련어 k평균, 계층 군집, 차원축소, 클러스터(8장)</sub>

- **k평균** `k-Means` — 중심점을 k개 놓고 가까운 것끼리 묶기를 반복하는 방법. 빠르고, 시작 위치에 따라 결과가 달라지며, 동그란 모양의 묶음만 잘 찾는다.
- **계층 군집** `Hierarchical Clustering` — 가까운 것끼리 차례로 합쳐 나무 모양으로 만드는 방법. 개수를 미리 안 정해도 되고 느리다.
- **밀도 기반 군집** `Density-Based Clustering` — 데이터가 빽빽한 영역을 묶음으로 보는 방법. 모양이 이상해도 찾고, 어디에도 안 속하는 점을 잡음으로 남긴다.
- **차원축소** `Dimensionality Reduction` — 항목이 많은 데이터를 적은 수의 축으로 줄여 표현하는 일. <sub>관련어 주성분 분석, 임베딩(22장에서 다룬다), 차원의 저주(11장)</sub>
- **주성분 분석** `Principal Component Analysis, PCA` — 데이터가 가장 넓게 퍼진 방향을 차례로 찾아 그 축으로 데이터를 다시 적는 방법. <sub>관련어 차원축소, 고유값(11장), 군집화</sub>
- **t-SNE와 UMAP** `t-SNE and UMAP` — 고차원 데이터를 2차원 그림으로 그리는 방법들. 가까운 것끼리 가깝게 유지하려 하고, 묶음 사이의 거리와 크기는 믿으면 안 된다.
- **이상 탐지** `Anomaly Detection` — 보통과 다른 데이터를 찾아내는 일. <sub>관련어 클래스 불균형(12장), 이상치(10장), 분포 이동(16장에서 다룬다)</sub>

**어느 자리에 무엇을 먼저 써 보나**

| 데이터 모양 | 먼저 써 보는 것 | 왜 |

|---|---|---|

| 표 형태, 수만 행 | 그래디언트 부스팅 | 빠르고 강하다 |

| 표 형태, 해석이 필요 | 로지스틱 회귀, 결정트리 | 읽을 수 있다 |

| 이미지 | 합성곱 신경망 | 격자 구조를 쓴다 |

| 텍스트 | 사전학습된 언어 모델 | 이미 배운 것이 많다 |

| 정답이 없음 | 군집화, 차원축소 | 구조를 먼저 본다 |

| 데이터가 아주 적음 | 단순한 선형 모델 | 복잡하면 외운다 |

순서가 있다. 단순한 것을 먼저 돌려 기준선을 만들고,
그것보다 나은지로 복잡한 모델을 판단한다.
기준선 없이 복잡한 모델의 점수만 보면 그 점수가 좋은지 알 수가 없다.

- **기준선** `Baseline` — 비교의 출발점으로 삼는 단순한 모델이나 규칙. 이것보다 못하면 복잡하게 만든 의미가 없다. 42장에서 다시 나온다.
- **설명 가능성** `Explainability` 〔유동〕 — 왜 그렇게 판단했는지 사람이 이해할 수 있는 정도. 무엇을 설명으로 인정할지가 사람마다 달라 낱말이 흔들린다.
- **해석 가능한 모델** `Interpretable Model` — 구조 자체가 읽히는 모델. 선형 모델과 얕은 결정트리가 여기 속한다.
- **SHAP과 LIME** `SHAP and LIME` — 복잡한 모델의 판단을 항목별 기여로 나눠 설명하려는 방법들. 앞은 여럿이 함께 낸 성과를 각자 몫으로 나누는 섀플리 값에서 왔고, 뒤는 판단 하나 주변만 단순한 모델로 흉내 내는 방식이다. 둘 다 근사이고, 서로 다른 설명을 내놓기도 한다.

## 자주 헷갈리는 짝

- **회귀 (과제)와 로지스틱 회귀** 같은 낱말이 들어 있는데 로지스틱 회귀는 분류 모델이다.
이름이 역사적인 이유로 붙었다.
- **배깅과 부스팅** 같은 점은 둘 다 여러 모델을 합친다는 것.
다른 점은 방식이다. 배깅은 따로 만들어 평균 내고 부스팅은 앞의 오차를 이어 고친다.
- **커널 (기법)과 커널 (합성곱)** 같은 글자이고 뜻이 다르다.
앞은 두 점의 유사도를 재는 함수이고 뒤는 이미지를 훑는 작은 가중치 격자다.
- **군집화와 분류** 같은 점은 둘 다 데이터를 무리로 나눈다는 것.
다른 점은 정답이 있는가다. 군집화에는 정답이 없어서 잘했는지 판단이 어렵다.
- **가지치기 (트리)와 가지치기 (신경망)** 같은 낱말이고 목적이 다르다.
앞은 과적합을 막고 뒤는 28장에서 모델을 작게 만든다.

## 지금 움직이는 것

표 형태 데이터에서 부스팅이 신경망을 계속 이기는 상황이 이어지고 있다. 언어 모델로 표 데이터를 다루려는 시도가 늘었지만, 정확도보다는 설정이 덜 필요하고 설명을 문장으로 만들 수 있다는 쪽에서 값을 찾는 중이다. 어느 쪽이 낫다기보다 무엇을 원하는가에 따라 갈린다.

## 더 볼 곳

여기서 나온 시그모이드와 가중합이 17장의 뉴런이 된다. 평가하는 방법은 바로 다음 15장이고, 과적합 대책은 16장이다. 가까운 것을 찾는 발상은 34장에서 벡터 검색으로 돌아온다.
