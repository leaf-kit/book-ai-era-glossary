# 16장 과적합과 일반화

<sub>3부 기계학습의 뼈대 · 표제어 41개 · 도해 3개</sub>

> **여는 지도** — 이 장의 낱말 마흔하나. 외운 것과 배운 것을 가르는 장치들

이 장은 학습 데이터는 잘 맞히는데 새 데이터에서는 안 되는 상태를 다룬다. 13장에서 정의한 일반화를 실제로 얻는 방법들이다.

원인은 하나로 요약된다. 모델이 규칙 대신 잡음을 배웠다. 데이터에는 진짜 규칙과 그 데이터에만 있는 우연이 섞여 있는데, 표현력이 충분하면 우연까지 맞춘다. 그리고 우연은 다음 데이터에 없다.

대책이 셋이다. 모델을 덜 자유롭게 만들거나, 데이터를 늘리거나, 일찍 멈춘다. 어느 것도 공짜가 아니다. 덜 자유롭게 하면 진짜 규칙도 놓치고, 데이터는 돈이 들고, 일찍 멈추면 덜 배운 채로 끝난다.

5부에서 이 이야기가 규모 때문에 달라진다. 파라미터가 데이터보다 많은 상황이 기본이 되었는데, 그런데도 일반화가 된다. 이 장의 고전적인 설명으로는 잘 안 풀리는 자리이고, 마지막에 그것을 적는다.

## 표제어

### 오차를 나눠 보기

#### 편향과 분산

<sub>Bias and Variance</sub>

**모델의 오차를 두 원인으로 나눠 보는 틀. 하나는 너무 단순해서, 다른 하나는 너무 흔들려서 생긴다.**

갈리는 자리 — 같은 낱말이 표집 치우침, 신경망의 더하는 값, 사회적 차별로도 쓰인다

<sub>관련어 과적합, 과소적합, 모델 용량, 학습 곡선</sub>

- **모델 용량** `Model Capacity` — 모델이 표현할 수 있는 함수의 다양함. <sub>관련어 편향과 분산, 과적합, 파라미터(13장), 이중 하강</sub>
- **과적합** `Overfitting` — 학습 데이터의 우연까지 맞춰 버려서 새 데이터에서 성능이 떨어지는 상태. <sub>관련어 과소적합, 조기 종료, 규제, 암기(13장)</sub>
- **과소적합** `Underfitting` — 모델이 단순하거나 덜 배워서 학습 데이터도 못 맞히는 상태. 규제를 풀고 모델을 키우고 더 오래 돌린다.
- **학습 곡선** `Learning Curve` — 학습이 진행되며 손실이 어떻게 변하는지 그린 그래프. 학습 손실과 검증 손실을 같이 그려야 뜻이 생긴다. 25장에서 다시 나온다.
- **오컴의 면도날** `Occam's Razor` — 같은 것을 설명한다면 단순한 쪽을 고르라는 오래된 원칙. 규제의 밑에 깔린 생각이다.

### 모델의 자유를 줄이기

#### 규제

<sub>Regularization</sub>

**모델이 너무 자유롭게 맞추지 못하도록 제약을 걸어 일반화를 돕는 장치의 총칭.**

갈리는 자리 — 한국어로 정규화라고도 번역되어 다른 두 낱말과 섞인다

<sub>관련어 L2 규제, 드롭아웃, 가중치 감쇠, 정규화 (벡터)(11장)</sub>

- **L2 규제** `L2 Regularization` — 가중치의 제곱합을 손실에 더하는 방식. 전체적으로 작게 만들고 0으로 만들지는 않는다.
- **L1 규제** `L1 Regularization` — 가중치의 절댓값 합을 더하는 방식. 필요 없는 항목의 가중치를 정확히 0으로 만들어 항목 선택 효과가 있다.
- **가중치 감쇠** `Weight Decay` — 갱신할 때마다 가중치를 조금씩 줄이는 방식. L2 규제와 같은 효과인 경우가 많고, 최적화 방법에 따라 미묘하게 다르다.
- **드롭아웃** `Dropout` — 학습할 때마다 뉴런의 일부를 무작위로 꺼서 특정 경로에 의존하지 못하게 하는 규제. <sub>관련어 규제, 앙상블, 층(17장에서 다룬다)</sub>
- **잡음 주입** `Noise Injection` — 입력이나 가중치에 일부러 작은 잡음을 섞는 방식. 조금 흔들려도 답이 같아지게 만든다.
- **라벨 스무딩** `Label Smoothing` — 정답에 1 대신 0.9를 주는 식으로 확신을 낮추는 방식. 과도한 확신을 줄이고 보정을 개선한다.

### 언제 멈출 것인가

- **조기 종료** `Early Stopping` — 검증 손실이 더 이상 안 줄어들면 학습을 멈추는 방법. <sub>관련어 검증 손실, 체크포인트(13장), 학습 곡선</sub>
- **검증 손실** `Validation Loss` — 검증 집합에서 잰 손실. 이 값이 올라가기 시작하는 지점이 과적합의 시작이다.
- **인내** `Patience` — 검증 손실이 안 좋아져도 몇 번까지 기다릴지 정한 값.
- **체크포인트 선택** `Checkpoint Selection` — 학습이 끝난 뒤 여러 시점 중 가장 좋은 것을 고르는 일. 마지막 시점이 최선이 아닌 경우가 흔하다.

### 데이터로 푸는 방법

**과적합을 줄이는 방법과 그 대가**

| 방법 | 무엇을 하나 | 대가 |

|---|---|---|

| 데이터 늘리기 | 진짜 예시를 더 모은다 | 돈과 시간 |

| 증강 | 있는 것을 변형해 늘린다 | 변형이 뜻을 깨면 해롭다 |

| 규제 | 가중치를 눌러 둔다 | 세게 걸면 과소적합 |

| 드롭아웃 | 일부를 꺼서 의존을 막는다 | 학습이 느려진다 |

| 조기 종료 | 일찍 멈춘다 | 덜 배운 채로 끝날 수 있다 |

| 모델 줄이기 | 표현력을 낮춘다 | 어려운 패턴을 못 배운다 |

| 앙상블 | 여러 개를 합친다 | 비용이 개수만큼 |

첫 줄이 가장 확실하고 가장 비싸다.
나머지는 전부 데이터가 부족한 상황을 견디는 방법이다.
그래서 데이터를 늘릴 수 있으면 다른 것을 손대기 전에 그것부터 한다.

- **데이터 늘리기** `More Data` — 진짜 데이터를 더 모으는 일. 과적합에 대한 가장 확실한 답이고 가장 비싸다.
- **혼합 증강** `Mixup` — 두 데이터를 섞어 새 데이터를 만들고 정답도 그 비율로 섞는 방식. 경계 근처를 부드럽게 만든다.
- **교차검증 활용** `Cross-Validation for Selection` — 여러 설정을 교차검증으로 비교해 고르는 일. 데이터가 적을 때 한 번의 분할보다 안정된 판단을 준다.

### 모른다는 것을 아는가

- **불확실성 정량화** `Uncertainty Quantification` — 모델이 낸 답을 얼마나 믿어도 되는지를 수로 적는 일. <sub>관련어 보정, 인식적 불확실성, 우연적 불확실성, 신뢰도</sub>
- **인식적 불확실성** `Epistemic Uncertainty` — 모델이 몰라서 생기는 몫. 그 영역의 데이터를 더 모으면 줄어든다.
- **우연적 불확실성** `Aleatoric Uncertainty` — 현상 자체에 있는 흔들림. 데이터를 아무리 모아도 안 줄어든다.
- **심층 앙상블** `Deep Ensemble` — 같은 구조를 다른 초기값으로 여러 번 학습시켜 답이 갈리는 정도를 불확실성으로 쓰는 방법. 계산이 몇 배로 든다.
- **몬테카를로 드롭아웃** `MC Dropout` — 무작위로 여러 번 돌려 평균을 보는 몬테카를로 방식을 드롭아웃에 적용한 것. 추론할 때도 드롭아웃을 켜 두고 여러 번 돌려 답이 얼마나 흩어지는지 본다. 앙상블보다 싸고 대신 거칠다.
- **컨포멀 예측** `Conformal Prediction` 〔신조〕 — 하나의 답 대신 정답이 들어 있을 구간이나 후보 집합을 내놓는 방법. 정해 둔 확률로 정답을 포함한다는 보장이 붙는다는 점이 다른 방법과 갈리는 자리다. <sub>생긴 때: 2020년 무렵부터 기계학습 쪽에서 널리 쓰인다</sub>
- **선택적 예측** `Selective Prediction` — 자신 없으면 답을 안 하고 넘기는 방식. 46장의 거절과 같은 발상이고, 넘기는 비율과 정확도의 절충이 생긴다.
- **분포 밖 탐지** `Out-of-Distribution Detection, OOD` — 배운 것과 다른 종류의 입력이 들어왔는지 알아내는 일. 46장의 분포 밖 입력을 실제로 잡아내는 장치다.
- **적대적 예제** `Adversarial Example` — 사람 눈에는 거의 안 달라 보이는데 모델은 전혀 다르게 판단하는 입력. 모델이 무엇을 보고 있는지가 사람과 다르다는 증거로 인용된다.
- **강건성** `Robustness` — 입력이 조금 흔들려도 답이 크게 안 바뀌는 성질. 정확도가 높은 것과 다른 성질이고, 따로 재야 한다.

### 배운 세상과 쓰이는 세상이 다를 때

#### 분포 이동

<sub>Distribution Shift</sub>

**학습할 때 본 데이터와 실제로 마주하는 데이터의 성질이 달라지는 현상.**

<sub>관련어 데이터 드리프트(12장), 분포 밖 입력(46장에서 다룬다), 재학습(45장에서 다룬다)</sub>

- **공변량 이동** `Covariate Shift` — 입력의 분포만 바뀌고 입력과 정답의 관계는 그대로인 경우.
- **개념 이동** `Concept Drift` — 같은 입력에 대한 정답 자체가 바뀌는 경우. 사기 수법이 바뀌는 것이 예다.
- **분포 밖** `Out-of-Distribution, OOD` — 학습에서 본 적 없는 종류의 입력. 모델이 자신 있게 틀리는 대표적인 자리다. 46장에서 다시 나온다.
- **보정** `Calibration` — 모델이 말하는 확률이 실제 빈도와 맞는 정도. <sub>관련어 임계값(15장), 신뢰도, 라벨 스무딩, 환각(46장에서 다룬다)</sub>
- **신뢰도** `Confidence` 〔유동〕 — 모델이 자기 답에 부여하는 확실함의 정도. 확률값을 뜻하기도 하고 말투의 단정함을 뜻하기도 해서 문서에서 섞인다.
- **과신** `Overconfidence` — 실제 정확도보다 높은 확률을 내놓는 성질. 깊은 신경망에서 흔하게 나타난다.
- **이중 하강** `Double Descent` 〔유동〕 — 모델을 키우면 검증 오차가 한 번 나빠졌다가 더 키우면 다시 좋아지는 현상. <sub>갈리는 자리: 현상은 여러 곳에서 보고되었는데 설명이 합의되지 않았고, 어느 조건에서 나타나는지도 정리 중이다 · 관련어 모델 용량, 편향과 분산, 스케일링 법칙(25장에서 다룬다)</sub>
- **암묵적 규제** `Implicit Regularization` — 규제를 따로 걸지 않았는데도 최적화 절차 자체가 만들어 내는 규제 효과. 확률적 경사하강의 흔들림이 그런 역할을 한다는 설명이 있다.
- **일반화 격차** `Generalization Gap` — 학습 성능과 검증 성능의 차이. 이 값이 크면 과적합이다.
- **그로킹** `Grokking` 〔유동〕 — 한참 동안 외우기만 하다가 훨씬 뒤에 갑자기 일반화가 되는 현상. 속속들이 이해한다는 뜻의 영어 속어에서 이름을 가져왔다. 작은 과제에서 관찰되었고 큰 모델에서 같은 일이 일어나는지는 확인 중이다.

## 자주 헷갈리는 짝

- **과적합과 분포 이동** 같은 점은 둘 다 실제 성능이 나쁘다는 것.
다른 점은 원인이다. 앞은 외운 것이고 뒤는 세상이 바뀐 것이다.
검증 집합으로 앞은 잡히고 뒤는 안 잡힌다.
- **규제와 정규화** 한국어 번역이 겹친다.
과적합을 막는 장치와 값의 범위를 맞추는 일은 다른 것이다.
- **L1과 L2** 같은 점은 둘 다 가중치를 눌러 둔다는 것.
다른 점은 0으로 만드는가다. L1은 만들고 L2는 안 만든다.
- **편향 (모델)과 편향 (신경망)** 같은 글자이고 뜻이 다르다.
앞은 단순해서 생기는 오차이고 뒤는 17장에서 더해 주는 값이다.
- **보정과 정확도** 같은 점은 둘 다 모델 품질을 나타낸다는 것.
다른 점은 확률값을 믿을 수 있는가다. 정확한데 보정이 나쁜 모델이 흔하다.

## 지금 움직이는 것

규모가 커지면서 이 장의 고전적인 처방이 덜 쓰이게 되었다. 데이터가 매우 많으면 과적합보다 덜 배우는 쪽이 문제가 되어서, 드롭아웃을 안 쓰고 규제도 약하게 거는 설정이 흔해졌다. 대신 분포 이동과 보정 문제는 오히려 더 중요해졌다. 배포된 모델이 오래 쓰이면서 세상이 바뀌는 속도를 따라가야 하기 때문이다.

## 더 볼 곳

여기서 나온 규제와 조기 종료가 18장의 학습 절차에서 실제로 쓰인다. 분포 이동은 45장의 갱신 고리로, 보정은 46장의 확신 문제로 이어진다. 이것으로 3부가 끝난다.
